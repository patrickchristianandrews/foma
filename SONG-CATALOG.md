# Song Library
12 recognizable public-domain compositions, using the existing FM1-Hero note-event arrangements by mlwilki (GPL-3.0-only), upstream https://github.com/mlwilki/FM1-Hero/blob/main/src/songs.h, source blob 975d771f50d44d90413958666d4f56732db59098. The source arrays are copied unchanged for these pieces; the playback engine and FM voices are Liquid Wave's. Some are shortened arrangements, not complete orchestral recordings. Modern songs omitted until arrangement and redistribution permissions are verified. Browse with SELECT/PRESETS, PLAY starts/stops, ALGORITHM chooses FM timbre, K1 sets level, ARP selects a random title. No network needed. Catalog never modifies generated songs or save data.
